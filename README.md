# Feriados do Ano

Projeto desenvolvido em **HTML, CSS e JavaScript** que permite ao usuário digitar um ano e consultar a lista de feriados daquele ano.

## Funcionalidades

* Digitar um ano.
* Buscar os feriados do ano informado.
* Exibir a data e o nome de cada feriado na tela.
* Utilizar uma API gratuita e sem cadastro.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Fetch API
* Brasil API

## API utilizada

O projeto utiliza a **Brasil API** para consultar os feriados nacionais.

Endpoint utilizado:

`https://brasilapi.com.br/api/feriados/v1/{ano}`

Exemplo:

`https://brasilapi.com.br/api/feriados/v1/2026`

## Estrutura do projeto

```text
projeto/
├── index.html
└── style.css
```

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Digite um ano.
4. Clique em **Buscar**.
5. Os feriados serão exibidos na tela.
